# 공개 API

본인이 발급한 **개인 액세스 토큰(PAT)** 으로 자기 데이터에 프로그램으로 접근한다.
기계가 읽을 스펙은 [`openapi.json`](openapi.json)에 있고(생성물), 이 문서는 스펙이
담기 어려운 **계약**을 적는다.

## 토큰 발급

설정 > 계정 > 액세스 토큰 > **새 토큰 발급**.

- 평문은 발급 화면에서 **한 번만** 보인다. 서버는 SHA-256 해시만 저장하므로 다시
  만들어 줄 수 없다 — 잃어버리면 폐기하고 재발급한다.
- 스코프는 `read`(기본)와 `read_write` 둘이다. **쓰기는 명시 선택이다.**
- 만료는 선택이다(미지정 = 무기한).
- **폐기는 즉시 적용된다.** 캐시가 없어 다음 요청부터 401이다.

```bash
curl -H "Authorization: Bearer wlpat_…" https://workout-log-eight.vercel.app/api/logs
```

## 무엇이 열려 있고 무엇이 아닌가

**기본은 거부다.** [`openapi.json`](openapi.json)에 적힌 경로만 PAT로 닿는다.
그 밖의 모든 경로는 **401**이다 — 새 엔드포인트가 생겨도 자동으로 열리지 않는다.

어느 스코프로도 열리지 않는 것:

| 영역 | 이유 |
|---|---|
| 계정·인증(`/api/auth/*`) | **토큰이 토큰을 낳으면 폐기가 의미를 잃는다** |
| 설정 변경(`/api/settings`) | 설정은 앱에서만 바꾼다 |
| 삭제(`DELETE`) | 프로그램 실수의 손실이 되돌릴 수 없다. MCP 도구 목록에 삭제가 있으면 LLM이 부를 수 있다 |
| 가져오기(`POST /api/me/import`) | `mode: "replace"`가 전부 지운다 |
| 텔레메트리·인프라 | 사용자 데이터가 아니다 |

> ⚠️ `/api/auth/*`는 웹 앱이 직접 처리하며 `Authorization` 헤더를 **아예 읽지 않는다**.
> PAT를 붙여도 인증되지 않은 응답이 온다(상태 코드는 경로마다 다르다).

## 멱등성 — 세션 저장

`POST /api/logs`에 `clientMutationId`를 함께 보내면 **exactly-once**가 보장된다.
네트워크가 끊겨 재시도해도 세션이 둘로 늘지 않는다.

```jsonc
{
  "clientMutationId": "b6f0…",   // 클라이언트가 만드는 고유 id
  "performedAt": "2026-08-26T10:00:00.000Z",  // clientMutationId를 쓰면 필수
  "sets": [{ "exerciseName": "Bench Press", "weightKg": 60, "reps": 5, "setNumber": 1 }]
}
```

- 서버가 요청 본문의 **정규 해시**를 함께 저장한다. 같은 `(id, 해시)`로 다시 오면
  이전 결과를 그대로 돌려준다.
- `clientMutationId`를 쓸 때 `performedAt`이 없으면 **400**이다.
- 본문이 달라진 채 같은 id로 보내면 **새 요청**으로 취급된다 — 재시도가 아니라
  다른 요청이기 때문이다.

## 요청 한도

| 스코프 | 한도 |
|---|---|
| 읽기 | 120 / 분 |
| 쓰기 | 30 / 분 |

키는 **토큰 해시**다. IP가 아니라 토큰별이라 같은 네트워크의 다른 클라이언트가
서로를 굶히지 않는다.

초과하면 **429**와 `Retry-After`(초) 헤더가 온다.

> 이 한도가 막으려는 것은 사람이 아니라 **루프**다. MCP를 붙인 LLM은 초당 수십 번도
> 간다 — 사람이 새로고침하는 것과 규모가 다르다.

## 응답 스키마가 없는 이유

스펙에 경로·권한·한도는 있지만 **응답 본문 스키마는 없다.** 22개 엔드포인트의 응답
형태를 손으로 유지하면 곧 거짓말이 되고, 공개 문서의 거짓말은 없는 문서보다 나쁘다.
응답 형태는 실제로 한 번 호출해 확인하는 편이 정확하다.

경로·스코프·한도는 반대다 — **코드에서 생성되고 유닛이 드리프트를 막는다**
(`apps/api/src/openapi-spec.test.ts`).

## 스펙 재생성

```bash
pnpm -C apps/api build:openapi
```

공개 표면을 넓혔는데 설명을 안 쓰면 스크립트가 실패한다. 재생성을 잊으면 유닛이
실패한다.
