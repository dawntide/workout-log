## 1. 배경 — 왜 지금, 왜 슬롯 교체인가

- **근력 ≥ 요구치, 스킬은 초반**: 중량풀업 1.47×BW는 OAP 근력 전제(통상 1.5×BW 싱글 / +25~45% BW × 3~5렙 범위)의 경계선이고, 70 kg 리컴프 시 1.57×. 반면 자가 어시스트 사다리에서는 2단(전완)에서 1~2렙에 4개월 정체. 이 조합은 병목이 당기는 힘이 아니라 **비대칭 전달·팔꿈치 밀착 포지션·항회전**이라는 교과서적 신호다. 중량풀업 증량으로는 채워지지 않는다 → 특이 슬롯이 필요.
- **4개월 정체의 원인은 용량·배치**: 매 세션 마무리(피로 상태), 1~2렙, 진행 규칙 없음, 어시스트 지점 미고정(연속값). 유지 용량이지 진행 용량이 아니다.
- **딥스와 다른 이유**: 딥스는 기존 프레스와 중복이라 C5로 거부했다. OAP 스킬 워크는 목표(G6)의 필수 요소이고 어떤 기존 종목도 대체하지 못한다 → 목표에 의한 C5 개정은 정당하다. 단 6종목 확장이 아니라 **PULL 계열 슬롯 교체**로 세션 시간·회복 예산을 보존한다.
- **조직 리스크가 타임라인을 결정**: OAP 워크는 팔꿈치(이두건·상완근)·회전근개 부상률이 높은 대표 종목이며, 근육보다 힘줄 적응이 느리다. 4개월 무통 이력은 현재 부하 수준의 내성 증거이지 면허가 아니다 → 단계 승급 게이트와 네거티브 해금 조건을 둔다.

## P1. OAP 스킬 슬롯

### P1.1 위치와 빈도
- **BP 집중 세션 3번 슬롯** (v1.3의 `PULL 볼륨 2×6` 자리). 순서: SQ → BP 집중 3×3 → **OAP 스킬** → OHP.
- 헤비 풀업(PULL 집중)이 없는 날이므로 48h 분리가 구조적으로 보장된다. 주 3회 기준 노출 ~1.5회/주 (권장 상한 1~2회/주 충족).
- **마이크로 세션 불변** (SQ V 2×5 + BP 볼륨 1 + PULL 볼륨 1×6). OAP는 마이크로에 넣지 않는다 — 고장력 스킬 워크는 밀도 제한 세션의 목적과 상충.
- PULL 집중 세션 불변 (헤비 중량풀업 = 근력 엔진 유지).

### P1.2 어시스트 사다리 — 고정 6단 (도르래 부재 → 서수 척도)
보조손이 당기는 팔을 잡는 위치를 고정해 판정 비교성을 확보한다. 위치는 아래 정의를 벗어나면 그 노출은 INVALID(EXTERNAL) 처리한다.

| 단 | 명칭 | 보조손 위치 정의 |
|---|---|---|
| 1 | 손목 | 당기는 팔의 손목 주름 바로 아래를 감쌈 |
| 2 | 전완 | 전완 중간점(손목~팔꿈치의 중점) — **시작 단** |
| 3 | 팔꿈치 | 팔꿈치 접힘부 바로 아래(전완 근위 끝) |
| 4 | 상박 | 상박 중간점 — **네거티브 해금 단** |
| 5 | 어깨 | 삼각근 상부/쇄골 부근. 수직 보조 거의 없음, 안정만 |
| 6 | 프리 | 보조손을 몸에서 뗌 = OAP |

- **팔별 독립 상태**: 좌/우 각각 현재 단, 연속 PASS 수, 연속 FAIL 수를 가진다.
- 그립: 회외(친업) 또는 중립. 첫 목표는 원암 친업. 링이 있으면 회내→회외 회전 그립 허용. 그립은 계획 내 고정.
- 턱이 당기는 팔의 손 위로 올라와야 유효 렙.

### P1.3 처방
- **어시스트 OAP 팔당 2×3** (현재 단 기준). 좌·우 1세트씩 = **1 페어 세트**로 회계 → 슬롯 2세트, 세션 총 10 작업세트 유지.
- 휴식: 페어 간 2~3분, 팔 교대 간 30~60초.
- **4단(상박) 이상 도달한 팔에 한해** 추가: 원암 네거티브 **팔당 1×2** (5~8초 통제 하강, 보조손으로 올라가 프리로 내려옴). 해당 팔이 4단에서 최초 승급 조건(P1.4)을 충족한 다음 노출부터.
- 세트 종료 원칙은 REF5 §11과 동일(명백한 감속·폼 붕괴 전 종료, 추가 렙 없음).

### P1.4 판정·승급·강등 (REF5 §11 재사용, 팔별)
- 판정은 팔별로 예정 렙(2×3=6) 대비 총 부족 렙과 종료 사유로 산출: PASS / HOLD(1 부족 또는 완료+감속) / FAIL(≥2 부족) / INVALID(SAFETY·EXTERNAL).
- **승급**: 같은 단에서 **유효 노출 3회 연속 PASS** → 단 +1. 승급 시 연속 카운터 초기화.
- **강등**: 같은 단에서 **유효 노출 2회 연속 FAIL** → 단 −1 (1단 미만 불가). 초기화.
- HOLD는 승급 연속을 끊되 강등 연속도 끊는다(중립).
- INVALID는 어느 연속도 진행시키지 않는다.
- 6단(프리)의 승급 조건 충족 = **OAP 달성**. 이후 유지 처방은 5단 어시스트 2×3 + 프리 1×1 (주 1회 이하) — 달성 후에도 최소 빈도 원칙.
- OAP 판정은 PULL 집중 판정창·veto·정체 상태와 **완전 독립**. PULL 계열 스트림에 섞지 않는다.

### P1.5 엔진·스키마 영향
- 스트림: `PULL_VOLUME_NORMAL` 제거 (정상 세션에 PULL 볼륨이 더 이상 없음). `PULL_VOLUME_MICRO`는 유지되어 PULL 집중창 veto의 유일한 볼륨 입력이 된다. 총 흐름 12 → 11.
- 신규 상태: `oap.left/right = { rung: 1..6, passStreak, failStreak, negativesUnlocked }`.
- 신규 종목 정체성 `ASSISTED_OAP` (좌/우 라벨 포함). §5.3 캘리브레이션 대상 아님(허용 목록에 넣지 말 것).
- 프로토콜 `1.4`, 프로그램 버전 `4`, 런타임·스냅샷 스키마 `4`, 시작 구성 `3`(OAP 시작 단 지정 가능: 기본 2, 좌/우 각각).
- §3.2 순도 경계 개정: "정확히 다섯 종목" → "다섯 종목 + OAP 스킬 슬롯(BP 집중 세션 한정)". 그 외 종목 추가 금지는 유지.
- 획득률 표출(§18)에 OAP 좌/우 현재 단과 연속 PASS를 추가.

### P1.6 명시적 트레이드오프 (v1.2가 누락했던 종류의 공개)
- PULL 주간 세트: v1.3의 ~8 → **~6 + OAP 페어 ~3/주.** 저강도 광배 근비대 볼륨은 감소하고, 고장력 단측 당기기 자극이 대체한다. G6 우선순위에 따른 의식적 교환이다.
- PULL 집중창의 볼륨 veto 입력이 마이크로 흐름만 남아 veto 발생 빈도가 낮아진다(판정이 다소 관대해짐).
- 되돌리기 조건: 팔꿈치 통증이 2주 이상 지속되거나 PULL 집중창이 2연속 유지로 가면 OAP 슬롯을 PULL 볼륨 2×6으로 복귀(v1.3 처방)한다 — 플래그 하나로 전환 가능하게 구현.

## P2. PULL 시작값 교정 + 캐리포워드

- 실측 1RM 총 110 → §5.3 역계수: floor2.5(110 × 87.5/108) = **87.5** (v1.3 시작 82.5는 실제의 75%로 설계 의도 81%보다 낮았음 — 사용자가 세션 2회차에 감지한 "강도 낮음"의 원인).
- **캐리포워드 규칙** (v1.4 새 계획 시작값): 각 종목 = v1.3 계획 종료 시점의 **판정 반영된 직접 기준**. 단 PULL은 `max(캐리값, 87.5)`.
  - 예: v1.3 첫 창에서 SQ INCREASE면 H3 82.5, 아니면 80. BP 동일. DL·OHP도 창이 닫혔으면 반영.
- OAP 시작 단: 좌/우 모두 2(전완). 첫 2회 노출 연속 FAIL이면 강등 규칙으로 1단 자동 재배치.
- `ohpMicroloading`: v1.3 설정 유지.

## P3. 운영 가이드 (§19.4 확장, 권장)

1. **팔꿈치 프로토콜**: (a) OAP 슬롯 전날·당일 클라이밍 금지 (헤비 풀업과 같은 48h 규율) (b) 팔꿈치·이두건 불편감이 세트 중 발생하면 해당 슬롯만 SAFETY INVALID, 세션은 계속 (c) 새 단 도달 후 2주는 승급 조건과 무관하게 그 단에 머묾 (힘줄 적응 창) (d) 통증이 2회 노출 연속이면 P1.6 되돌리기 검토.
2. **마무리 딥스 제거**: 팔꿈치 장부 교체(딥스 out, OAP in). 4개월간 하던 마무리 어시스트 OAP도 슬롯으로 흡수 — **이중 노출 금지**.
3. **그립**: 중량풀업은 숄더~내로우 폭으로 고정(OAP 포지션 특이성, 계획 내 불변). OAP는 친업/중립.
4. **워밍업 부속 추가** (익스텐션과 같은 지위, 프로그램 밖): 원암 행잉 손가락 보조 단계 2×10~20초(그립·회전근개·견갑 준비) + 손목 굴곡근 편심 1×10. OAP 슬롯 있는 날만.
5. **1RM 시도 금지**: 110 싱글은 유효한 캘리브레이션 데이터였으나 REF5 순도 밖. 이후 시도는 하지 않는다.

## P4. 컷오버 절차

1. v1.3 계획을 **SQ 첫 하드 창(6회)이 닫힌 직후** 종료 (~재시작 후 3주, 2026-09 중순). 이 시점이 손실 최소 — BP/PULL 첫 창은 이미 닫혔고 SQ 창까지 판정을 받는다. 미완 창의 노출은 이월하지 않는다(§19.2 원칙).
2. v1.4 구현·배포 확인 → 새 계획 생성 → P2 캐리포워드 값 입력 (PULL 87.5 이상) → OAP 시작 단 2/2.
3. v1.3 계획 아카이브. v1.4 decoder는 v1.3 이하 스냅샷을 거부(§24.3 패턴 유지).
4. 첫 OAP 노출은 **팔당 2×3 완수 여부보다 폼(턱 위치·팔꿈치 밀착·항회전)을 우선** — 첫 2회는 캘리브레이션 노출로 본다.

## 테스트 요구 (구현 시)

- BP 집중 세션: 3번 슬롯이 ASSISTED_OAP(좌/우 2×3), 총 10세트 회계, PULL 볼륨 없음. PULL 집중·마이크로 세션 불변.
- 팔별 승급(3연속 PASS)·강등(2연속 FAIL)·HOLD 중립·INVALID 무진행. 1단 하한, 6단 승급 = 달성 플래그.
- 4단 최초 승급 다음 노출부터 네거티브 1×2 생성, 3단 이하 미생성.
- PULL 집중창 veto가 `PULL_VOLUME_MICRO`만 참조. OAP 결과가 PULL 판정창·스트림에 무영향.
- 되돌리기 플래그 ON 시 v1.3 처방(PULL 볼륨 2×6)으로 복귀, 상태 보존.
- 시작 구성 3: OAP 좌/우 시작 단 입력·검증(1~6), PULL 시작값 87.5 격자 검증.
- v1.3 스냅샷·프로토콜 거부. 기존 스위트 회귀 없음.
